# Aurelian Archive vault protocol

The Aurelian Archive is a fictional institution used to test document retrieval.

## Rotation

The vault code of the Aurelian Archive rotates every 13 days. The new code is announced only to the two night
curators.

## Override

In an emergency a curator can open the vault with the override phrase "amber lantern". Every use of the phrase must be
written in the incident book within one hour.
